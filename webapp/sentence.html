Record yourself signing one sentence, using both hands, at a natural pace. The recognizer picks the closest match from a catalog of 101 everyday ISL sentences.

ℹ️

This is not open-ended translation. It recognizes whichever of its known catalog sentences your signing best matches — see the full list below. Built from the ISL-CSLTR dataset (two native signers, ~5 recordings per sentence), so accuracy on a new signer is a genuine but modest estimateASL references are built by chaining real word clips from the WLASL dataset in ASL word order (no public dataset of whole ASL sentences recorded several times exists), so this is an early experiment — sign each word clearly — see how it works.
